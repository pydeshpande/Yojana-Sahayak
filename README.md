# 🏛️ Yojana Sahayak

> **A voice-first assistant for Indian government schemes, built on Sarvam AI APIs for the Sarvam Campus Program.**

Yojana Sahayak helps ordinary citizens discover and understand relevant central and state government schemes (yojanas) in their native Indian language.

---

## ⚡ Features

- **Multilingual Support:** Converses naturally in Indian languages (Hindi, Tamil, Telugu, Bengali, Marathi, etc.) or English.
- **Powered by Sarvam-105B:** Intelligently matches personal situations to matching government schemes, eligibility requirements, and next steps.
- **Voice Output via Bulbul v3:** Converts written recommendations into clear spoken voice output (`.wav`).
